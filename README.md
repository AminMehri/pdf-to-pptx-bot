# PDF to PPTX Telegram Bot 🤖  

A Telegram bot that converts PDF files to PowerPoint (PPTX) presentations instantly.  

## 🚀 Quick Start  

1. **Clone the repo**  
   ```bash
   git clone https://github.com/AminMehri/pdf-to-pptx-bot/
   cd pdf-to-pptx-bot
Set up environment variables
Create a .env file and add your Telegram bot token:
plaintext
BOT_TOKEN=your_bot_token_here
(Get a bot token from @BotFather if you don’t have one.)
Install dependencies
bash
pip install -r requirements.txt
Run the bot
bash
python main.py
📌 Usage

Send a PDF file to your bot, and it will reply with the converted PPTX file.
